# majiang-taiwan

台湾 16 张麻将拍照算台与连拉记账 iOS App。

和牌后拍一下（16 张底牌 + 1 张胡牌 = 17 张，含花牌与吃碰杠），端侧 Core ML（YOLOv8n）与 Gemini 双读认出牌面，纯 Swift 台湾 16 张麻将算台引擎自动计算台种、庄家连拉台数（连 $N$ 拉 $N$ = $2N+1$ 台）与底/台金额，一键记入四家轮庄账本，打完算出最少转账笔数。

## 目录结构

- `app/MajiangKit`：纯 Swift 核心库（牌面表示、端侧 + Gemini 双读管线、台湾 16 张麻将算台引擎、底台/连拉账本与最小转账结算）
- `app/MajiangApp`：SwiftUI iOS 客户端（相机取景、17 张手牌核对改牌、花牌与连庄设置、牌桌方桌与账本分享图）
